ОЧИСТКА СТАРТОВОГО ШАБЛОНА
==========================

Команда:
  npm run clean:starter

Предпросмотр без изменений:
  npm run clean:starter -- --dry-run

При обычном запуске команда сначала перечисляет план. Для применения нужно
вручную ввести CLEAN. Любой другой ответ отменяет операцию. В этом сеансе
автоматического подтверждения нет. Сама команда очистку не запускает.

ЧТО УДАЛЯЕТСЯ И ЗАЧЕМ
---------------------

1. src/pages/ComponentsPage.tsx
   Это демонстрационная страница-каталог. Она показывает компоненты шаблона,
   но в реальном приложении должна появиться собственная страница.

2. src/pages/ExamplesPage.tsx
   Это витрина примеров Zustand, React Hook Form, Zod, Motion и TanStack Virtual.
   Сами библиотеки остаются установленными: примеры удаляются, чтобы не смешивать
   демонстрационный интерфейс с кодом нового продукта.

3. src/store/example-counter-store.ts и
   src/store/example-counter-store.test.ts
   Это учебный счётчик Zustand и его тест. Папка src/store остаётся местом для
   настоящего состояния приложения.

4. tests/e2e/visual.spec.ts-snapshots/starter-page-chromium-win32.png
   Это снимок исходной стартовой витрины. Он больше не нужен после очистки.
   Эталоны визуальных тестов кнопки и поля ввода сохраняются.

ЧТО ПЕРЕПИСЫВАЕТСЯ
------------------

- src/pages/HomePage.tsx становится пустым рабочим холстом. Переключатели языка
  и темы остаются доступными.
- src/app/App.tsx оставляет маршрут главной и 404, удаляя маршруты витрин
  компонентов и интеграционных примеров. Lazy loading и Suspense сохраняются.
- index.html получает нейтральные заголовок и описание приложения.
- README.md и README.en.md обновляются: в них остаются стек, запуск, проверки
  и структура проекта, но больше нет описания демо-страниц.
- Unit-, e2e- и axe-тесты обновляются под чистую главную, переключатели,
  доступность главной и 404, а также реальные визуальные тесты UI-компонентов.
- package.json и package-lock.json получают нейтральное имя пакета my-react-app.

ЧТО ОСТАЁТСЯ И ЗАЧЕМ
--------------------

- src/components/ui: Button, Input, Card, Badge, Checkbox и Select — базовые
  переиспользуемые UI-компоненты.
- Тесты, Storybook-истории и MDX-документация компонентов — чтобы развивать,
  проверять и документировать свою библиотеку UI.
- src/app: роутер, Error Boundary, светлая/тёмная тема, переключение языка,
  TanStack Query и глобальные стили — полезная инфраструктура приложения.
- src/pages/NotFoundPage.tsx — готовая страница для неизвестных адресов.
- Vitest, Testing Library, Playwright, axe-core, ESLint, Prettier и CI — проверки
  качества и автоматизация проекта.
- Зависимости Zustand, React Hook Form, Zod, Motion и TanStack Virtual — они
  остаются установленными, чтобы подключать их по мере необходимости.
- public/brand/favicon.svg, LICENSE, .nvmrc, конфигурации Vite, TypeScript,
  Storybook и Playwright — настройки, статический ресурс, лицензия и версия Node.
- how-to-clean-project.txt — эта инструкция; команда её не удаляет.

ОГРАНИЧЕНИЯ
-----------

- Команда работает только с перечисленными файлами внутри текущего проекта.
- Она не удаляет node_modules, public, LICENSE, Git-историю, ваши новые файлы,
  настройки или исходники UI-компонентов.
- После подтверждения README и перечисленные исходники будут заменены версиями
  чистого шаблона. Перед CLEAN сначала прочитайте план и сохраните важные правки.
- Очистка не запускается автоматически при установке зависимостей или сборке.

После очистки проверьте изменения в Git и запустите:
  npm run all-tests
